🎧 Audio Streaming & Peer-to-Peer Communication

Real-time voice collaboration built with WebRTC, React.js, and Socket.IO

This project showcases a robust, peer-to-peer audio streaming application using React.js, WebRTC, Socket.IO, and a custom Node.js signaling server deployed on Heroku. Users can participate in real-time audio sessions with advanced features like device selection, mute controls, and cross-platform support.

  • 🔁 WebRTC-based media stream control and negotiation
  • 📡 Real-time signaling via Socket.IO and Express server
  • 🎚️ Audio device selection, mute/unmute toggles, error handling
  • ☁️ Scalable signaling server deployed on Heroku
