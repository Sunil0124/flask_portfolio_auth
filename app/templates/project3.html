🍽️ Food Hall Cafe Management System

Interactive menu and order tracking platform powered by ReactJS and MySQL

A complete web-based cafe management application designed to streamline food ordering and menu administration. Built with ReactJS and MySQL, this platform supports real-time order tracking, dynamic menu updates, and a responsive admin dashboard.

  • 📋 Dynamic menu configuration interface
  • 🔄 Real-time order tracking and status updates
  • 👨‍💼 Admin dashboard with CRUD functionality
  • ⚙️ Backend integrated with MySQL for persistence
